# 마스토돈 한국어 운영 핸드북

**Mastodon Korean Handbook** — 마스토돈(Mastodon) 서버를 직접 구축하고 운영하는 사람을 위한 비공식 한국어 실무 문서입니다.

> **문서 작성 초기 단계입니다.** 아래 목차는 작성 계획이며, 아직 공개되지 않은 문서도 포함합니다. 실제 명령어를 실행하기 전에는 적용 버전과 운영 환경을 반드시 확인해 주세요.

## 이 프로젝트의 목적

마스토돈 서버 운영에는 설치뿐 아니라 업데이트, 백업과 복구, 보안, 검색, 연합(Federation), 장애 대응까지 여러 작업이 필요합니다. 이 저장소는 운영 과정에서 얻은 경험을 다른 운영자도 재현하고 검토할 수 있는 **한국어 안내서**로 정리하는 것을 목표로 합니다.

초기에는 **Ubuntu와 Docker Compose를 이용한 자체 호스팅 환경**을 중심으로 작성하되, 특정 서버에 종속되지 않도록 설정값과 사례를 일반화합니다.

## 문서 목차 (작성 예정)

| 분야 | 다룰 내용 |
| --- | --- |
| 시작하기 | 서버 준비, 도메인 및 DNS, Docker 기반 설치, 초기 설정 |
| 일상 운영 | 상태 점검, 로그 확인, 업데이트, 점검 공지 |
| 백업과 복구 | 데이터베이스·미디어·설정 백업, 무결성 검증, 복구 연습 |
| 보안 | SSH 및 접근 권한, 비밀정보 관리, 보안 업데이트, GitHub Actions |
| 검색 | Elasticsearch·OpenSearch, 인덱싱과 재색인, Nori를 이용한 한국어 검색 |
| 연합우주 | ActivityPub와 연합 동작 원리, 서버 간 연결, 운영 정책 |
| 문제 해결 | 장애 진단, 점검 순서, 복구와 롤백 |

각 문서는 가능한 한 **적용 환경 → 사전 준비 → 실행 절차 → 확인 방법 → 문제 발생 시 복구** 순서로 구성합니다.

## 문서의 검증 상태

운영 환경에 적용하기 전, 문서의 검증 수준을 구분합니다.

- **실험 중:** 아이디어나 재현 실험 단계이며, 운영 환경 적용을 권장하지 않습니다.
- **테스트 검증:** 별도 실험 환경이나 CI에서 확인했으나, 실제 운영 배포와는 구별합니다.
- **운영 확인:** 실제 운영 과정에서 적용과 확인을 마쳤습니다. 다만 환경과 버전에 따라 결과가 달라질 수 있습니다.

검증되지 않은 내용을 검증된 절차처럼 소개하지 않으며, 중요한 변경에는 **백업·롤백 방법**을 함께 기록합니다.

## 보안 및 공개 원칙

공개 문서에는 비밀번호, API 토큰, SSH 개인 키, 복호화 키, 실제 환경 변수 값 등 **비밀정보를 포함하지 않습니다**. 서버 주소·계정·경로는 필요에 따라 예시값으로 치환합니다.

명령어를 그대로 복사하기 전에 대상 서버, 파일 경로, Docker 서비스 이름, 마스토돈 및 관련 소프트웨어 버전을 확인하세요. 특히 데이터 삭제, 데이터베이스 변경, 인덱스 재생성처럼 되돌리기 어려운 작업은 별도로 주의사항을 표시합니다.

이 저장소는 마스토돈 공식 프로젝트의 문서나 공식 지원 채널이 아닙니다. 공식 문서와 차이가 있을 때는 사용 중인 버전에 해당하는 공식 안내를 먼저 확인하세요.
